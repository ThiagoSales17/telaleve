- [Contribuição](../CONTRIBUTING.md) — preparação do ambiente, checks e pull requests.
- [Segurança](../SECURITY.md) — limites de uso e reporte responsável.

## Recursos

- `assets/` — imagens usadas na documentação e no README.

A documentação deve distinguir claramente funcionalidades implementadas, verificações automatizadas e validação manual ainda pendente. Não trate uma execução de CI como prova de compatibilidade em todo desktop ou dispositivo Android.
